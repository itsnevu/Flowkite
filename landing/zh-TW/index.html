免費的 AI 瀏覽器代理

一個會先問過你的瀏覽器代理。

告訴它你要做什麼。Flowkite 會在你的瀏覽器裡完成，遇到重要的事會先問你。

試著這樣問： 「在三家商店裡找出最便宜的 AeroPress 濾紙，然後下單。」

加到 Chrome 下載 zip

免費、免帳號，使用你自己的 AI 金鑰。

看它運作

「先問過你」長這個樣子。

功能

幫你做事，決定權在你。

  • 先給計畫

    先讓你看計畫，等你同意才動手。

  • 花錢前先問

    購買、刪除或輸入密碼，一定要你點頭。

  • 看得見它在做什麼

    標著 Flowkite 的游標會顯示每次點擊，換頁時也會告訴你。

  • 技能

    研究、購物、填表等現成流程。輸入 / 就能選。

  • 一個分頁，一個 Flowkite

    每個分頁都有自己的面板，代理只在那個分頁工作。

  • 金鑰留在你手上

    沒有伺服器、沒有帳號。金鑰和資料都留在你的瀏覽器。

安裝

兩分鐘就能開始。

  1. 1 加到 Chrome

    在 Chrome 線上應用程式商店按一下即可。

    加到 Chrome

  2. 2 加入你的 AI 金鑰

    在側邊面板開啟「設定」，貼上金鑰。

  3. 3 開始使用

    輸入你要做的事，然後核准計畫。

想改用 zip 安裝？

  1. 下載 flowkite.zip 並解壓縮。

  2. 開啟這個網址：

    chrome://extensions/

  3. 開啟右上角的開發人員模式。

  4. 按載入未封裝項目，選擇解壓縮後的資料夾。

常見問題

快速解答。

免費嗎？

是的。沒有付費方案，也不需要帳號。你只需支付 AI 供應商的用量費用，透過 Ollama 使用本機模型則完全免費。

我的 API 金鑰會去哪裡？

金鑰留在你的瀏覽器，並直接送到你的 AI 供應商。Flowkite 沒有伺服器。

哪些資料會離開我的電腦？

只有任務需要的內容：正在處理的頁面、你開啟的分頁標題，以及開啟視覺功能時的螢幕截圖，送到你選擇的 AI 供應商。詳細內容請見隱私權政策。

可以使用本機模型嗎？

可以，透過 Ollama 或任何相容 OpenAI 的端點。

支援哪些瀏覽器？

Chrome 和 Edge。
